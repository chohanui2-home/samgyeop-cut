# 내가 정육왕

도마 위 통삼겹살을 **눈대중으로 똑같이 소분**하는 정육 놀이입니다.
가위 선을 움직여 반띵·정량·3팩·4팩으로 잘라 내고, `✂️ 싹둑 자르기!`를 누르면 조각마다 실제 무게(g)가 공개됩니다.

**바로 플레이:** https://chohanui2-home.github.io/samgyeop-cut/

## 게임 규칙

- 한 판은 **5문제(5주문)** 입니다. 화면 맨 아래 탭에서 6단계 중 아무 단계나 바로 골라 시작할 수 있습니다.
- 자르기 전에는 **총 무게만** 알려 줍니다. 조각 무게는 눈대중으로 맞혀야 하고, 자른 뒤에 정확한 g이 공개됩니다.
- 채점은 **무게의 오차**로 합니다.
  - 똑같이 나누는 주문(반띵·3팩·4팩·5팩·6팩) → 가장 무거운 조각과 가장 가벼운 조각의 차이
  - 목표 무게 주문(1인분·비정형 정량) → 목표 g과 실제 g의 차이
  - 점수 = 1000 − (오차 × 5)점, 등급은 `👑 정육점 마스터`(0–2g) · `🔥 고깃집 사장님`(3–5g) · `✨ 황금 눈대중`(6–10g) · `🐷 조금만 더 꿀!`(11g 이상)
- **가위 선은 최소 5% 간격**을 지키며, 서로를 넘어가거나 고기 밖으로 나가지 않습니다.

## 6단계

| 단계 | 이름 | 주문 내용 | 가위 선 |
|---|---|---|---|
| 1 | 반띵 | 균일한 통삼겹을 정확히 절반으로 | 1개 |
| 2 | 1인분 | 목표 무게(150·180·200·220·250g)만큼 왼쪽부터 잘라 내기 | 1개 |
| 3 | 3팩 소분 | 똑같이 3조각으로 | 2개 |
| 4 | 4팩 소분 | 똑같이 4조각으로 | 3개 |
| 5 | 모양 다른 고기 | 한쪽은 두껍고 한쪽은 얇은 비정형 통삼겹에서 정량 또는 반띵 | 1개 |
| 6 | 정육왕 주문 | 반띵·정량·3팩·4팩·5팩·6팩(다인분)·비정형 정량·비정형 반띵이 5문제 동안 랜덤으로 | 주문마다 |

5단계와 6단계의 비정형 고기는 **두께(밀도)가 위치마다 달라서** 길이의 절반이 무게의 절반이 아닙니다. 화면에 그려진 고기 모양 자체가 그 두께를 그대로 그린 것이라, 눈으로 면적을 재는 것이 곧 무게를 재는 것이 됩니다.

## 조작

- 고기 위를 **한 손가락으로 터치하거나 좌우로 드래그**하면 가장 가까운 가위 선이 따라옵니다.
- 선이 여러 개일 때는 `1번 선 / 2번 선 / …` 칩으로 옮길 선을 고르고, 아래 슬라이더로 0.5%씩 미세 조정합니다.
- PC에서는 `←` `→`로 0.5% 이동(Shift를 누르면 2%), `Enter`로 자르기, 숫자 키로 선 선택.

## 특징

- **정확한 무게 계산** — 조각 무게는 모두 정수 g이고, **조각 합이 통삼겹 총 무게와 1g도 틀리지 않습니다**(최대 잔여법으로 보정).
- **비정형 고기 적분** — 위치별 두께 함수를 400칸 누적표로 적분해 무게를 구하고, 같은 함수로 고기 그림을 그립니다.
- **새로운 스킨** — 크림 베이지 배경에 불판 주황·코랄, 나무 도마. 요리사 모자 쓴 아기돼지 셰프와 반짝이는 가위 친구가 대기·조준·환호·아쉬움 표정으로 반응합니다.
- **효과음** — Web Audio API로 만든 `싹둑!`·성공 딩동·지글 소리, 음소거 토글(설정은 브라우저에 저장).
- **기록** — 단계별 최고 점수를 저장하고, 탭에 ★ 표시. 결과 화면에서 **친구에게 공유하기**.
- **앱처럼 설치** — 홈 화면에 추가하면 전체화면 앱으로 열립니다(manifest 내장).
- 외부 CDN·폰트·이미지 **0개**. 파일 하나만 보내도 그대로 열립니다.

## 파일

- `index.html` — 게임 전체가 들어 있는 단일 파일(그림은 인라인 SVG, 소리는 Web Audio API).
- `app_template.html` — 빌드용 템플릿(아이콘 자리표시자 포함).
- `build.py` — 아이콘 주입, 단일 파일 규칙 검사 후 `index.html` 생성.
- `test_app.py` — QuickJS로 게임 스크립트를 실제 실행해 무게 합산·비정형 적분·가위 선 이동·채점·5문제 완주·기록·공유를 검사하는 테스트(137개 항목).

## 다시 빌드하기

```bash
python3 build.py      # index.html 생성 (단일 파일 검사 포함)
python3 test_app.py   # 테스트 (quickjs 파이썬 모듈 필요)
```
